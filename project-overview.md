I'm a UX/UI designer from Sweden with frontend knowledge trying to land my first job after my finished studies. I want to re-design and re-build my portfolio with Cursor for more control, possibilities and storage. This will be that project.

Initially I want to setup the portfolio with Vite, React, TailwindCSS since I have worked with those before. But I am open for suggestions like Node.js or other emerging languages you see fit. I want to do version control, backup and switching between devices with git & github.

I want the code to be slim and efficient and made with best practices in mind. The code should be well-structured for ease of editing and for when re-using components. I want us to use components in a professional manor.

For the styling, I will be adding tokens/classes to the tailwind.config.js that we always should adhere to using as a primary source of styling when it comes to colors, typography, fonts, spacing, border radiuses, padding, margins, sizes.

The portfolio will be targeted toward both international & swedish audiences, not exclusively Sweden. The content we use and the way we write must therefore be understandable for anyone, not only to designers or businesses in Stockholm/Sweden.
